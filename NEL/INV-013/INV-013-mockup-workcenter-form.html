BR-001 (BLOCK) — Only internal locations outside WH/Stock are accepted, on the screen, by import or by API. Any other value is refused on save with: "Components Location must be an internal location outside WH/Stock."
Administrators only (FDD §7) — Only Manufacturing Administrators can set it (standard access rights). A Manufacturing User gets the standard Odoo access-rights error.
Draft MOs only (BR-008) — Setting or changing the value updates the From of Draft MOs only. Confirmed, in-progress and done MOs keep their lines (132 open MOs had an unfinished MyData step on 20 Oct 2026).
