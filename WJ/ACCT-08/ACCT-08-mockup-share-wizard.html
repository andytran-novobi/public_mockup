Contact-first (R11 / D-009) — Recipients are existing contacts; typing a loose name cannot quick-create one (native). A new vendor is created via Create and edit… before the invite goes out — so the contact always exists first.
"Additional emails" hidden (BR-014) — the native raw-email invite path would create submissions with no linked contact (and there is no Create Contact anymore). The module hides it on toggle-enabled surveys.
On Send — Odoo creates one Participation per recipient with the Contact already linked and emails each a personal token link. Click Send to preview the form the vendor receives.
Reminders & redos — there are no automatic reminders; re-share to the same contact to remind or to issue a fresh link after a mistake. Each invite is a new Participation; repeating Update Contact is safe (BR-010).
